push_swap

## Description

The push_swap project consists of sorting a list of integers using two stacks (a and b) and a limited set of operations. The goal is to sort the list using the smallest possible number of operations. To do so, we had to implement the required functions ourselves and design a sorting algorithm.

This project is done as a team of two.

## Instructions

Compilation
bash
make
Usage
bash
./push_swap 3 2 1 5 4

The program prints the list of operations needed to sort the given integers.
